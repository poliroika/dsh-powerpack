# dsh-powerpack

Набор усилений для DeepSeek Harness: плагины, пресеты агента, скиллы, семантическая память и **полная русская локализация** плагина памяти — одним установщиком.

Не «только про русский»: локализация здесь один из слоёв. Основное — рабочий профиль DSH, который ставится на чистую установку и не ломает обновления.

Это не форк приложения и не его перепакованная сборка — это **дистрибутив настроек** (~2 МБ): скрипты + конфиги + словари. Ставится поверх официального DSH и обновляется вместе с ним.

## Что внутри

| Компонент | Что даёт |
|---|---|
| `install.ps1` | одна команда: ставит плагины, включает нужные бандлы, накладывает патч локали |
| `profile/local-presets/` | два своих пресета агента: **Быстрый** (лёгкий, без субагентов) и **Ресёрч** (веб без shell) |
| `localize/` | русская локализация `@a9i5k4/dsh-auto-memory`: кадр памяти, 19 описаний инструментов, 7 LLM-промптов, 1 298 захардкоженных строк UI, словари `I18N.ru` + `L10N.ru` |
| `skills/` | 5 скиллов: администрирование профиля DSH, проверка плагинов, правила памяти, квирки Windows-шелла, memory-keeper |
| `scripts/apply-profile.mjs` | идемпотентно добавляет бандл `session-search` и блок локали в `cordis.patch.yml` |
| `docs/PLUGINS.md` | список плагинов, зачем они и под какими лицензиями |

## Требования

- Windows 10/11, установленный **DeepSeek Harness Desktop** (запустить один раз, чтобы профиль создался).
- Node.js не нужен отдельно: используется Node из комплекта DSH.
- На время установки **закрыть DSH** — менеджер плагинов профиля должен быть свободен.

## Установка

```powershell
git clone https://github.com/<you>/dsh-powerpack
cd dsh-powerpack
powershell -ExecutionPolicy Bypass -File .\install.ps1
```

Параметры:

```powershell
.\install.ps1 -Profile desktop        # какой профиль ставить (по умолчанию desktop)
.\install.ps1 -SkipPlugins            # только локаль и пресеты, без установки пакетов
.\install.ps1 -Yes                    # без вопросов (для автоматизации)
```

После установки **перезапустить DSH**: появятся пресеты «Быстрый»/«Ресёрч», русская панель «Память», поиск по прошлым сессиям. Модель семантической памяти (~135 МБ) скачается при первом запуске.

## Что делает установщик

1. Проверяет, что найден профиль DSH и CLI `dsh`.
2. Ставит плагины через `dsh plugin --profile <p> add …` (pnpm, официальный путь).
3. Копирует `profile/local-presets` в профиль и регистрирует его как бандл.
4. Добавляет бандл `@deepseek-ai/dsh-experimental-session-search` и блок локали в `cordis.patch.yml`.
5. Запускает `localize/localize.mjs` — русификация плагина памяти (идемпотентно).
6. Печатает напоминание перезапустить DSH.

Установщик идемпотентен: повторный запуск ничего не дублирует.

## Обновления

- **Обновился плагин памяти** → `node localize/localize.mjs` (повторно) и перезапуск.
- **Обновился DSH** → перезапуск; если плагины несовместимы, `dsh plugin --profile desktop allow-version <pkg@ver> --dsh-version <ver> --accept-risk` — осознанное решение, не автоматика.
- **Обновился этот репозиторий** → `git pull`, затем `install.ps1` повторно.

## Удаление

```powershell
powershell -ExecutionPolicy Bypass -File .\uninstall.ps1
```

Скрипт снимает пакеты и управляемые блоки, но **не трогает** вашу память (`~/.dsh/memory`), сессии и скиллы — их удаляйте вручную, если нужно.

## Важно про приватность

Репозиторий **не содержит** и не должен содержать: `~/.dsh/.credentials.yaml`, сессии, журналы и заметки памяти, модели, `node_modules`, архивы бэкапов. Всё это остаётся на вашей машине.
