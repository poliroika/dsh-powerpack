# Плагины дистрибутива

Все пакеты ставятся из npm (`dsh plugin --profile desktop add …`), а не перепубликуются.
Профиль собирается как «слои»: базовые бандлы DSH → плагины → `cordis.patch.yml` → локализация.

## Включаются без установки (бандлы из комплекта DSH)

| Бандл | Зачем |
|---|---|
| `@deepseek-ai/dsh-experimental-session-search` | поиск и чтение прошлых сессий рабочей папки |
| `@deepseek-ai/dsh-experimental-agent-team-profile` | режим команды агентов (если нужен) |
| `@deepseek-ai/dsh-experimental-voice-input-bundle` | голосовой ввод (если нужен) |

Включаются добавлением имени в `dsh.profile.bundles` профиля (`package.json`). Установщик делает это для `session-search`; остальные — по желанию вручную.

## Не входят сознательно

- **Плагины, читающие ключи и сеть** (костметры, виджеты баланса, IM-боты) — требуют отдельного решения о доверии.
- **Тяжёлые рантаймы** (браузер на Electron, Python-движки, офисные пакеты) — ставятся по необходимости.
- **Плагин памяти C3-движок (BGE-M3, ~850 МБ)** — опциональный апгрейд точности, не входит.

## Локализация памяти

Плагин `@a9i5k4/dsh-auto-memory` китайский по умолчанию (интерфейс zh/en/ja, промпты и описания инструментов — китайские). `localize/localize.mjs` добавляет русскую локаль без правки логики:
кадр памяти, 7 LLM-промптов, 19 описаний инструментов, словари клиента (`I18N.ru` 672, `L10N.ru` 712), 1 298 захардкоженных строк, заголовки ledger и остатки диагностики.
Скрипт идемпотентен: после обновления плагина достаточно запустить его снова.
